# Collaboration And Initiative Patterns

Load this reference when the concrete question or an evidenced candidate concerns agent passivity, recommendation quality, repeated user-led redesign, or the boundary between initiative and unauthorized expansion.

Let the agent own discovery and judgment. The user should not need to identify every structural gap or repeatedly redesign shallow work after delivery. Let the user retain final authority over material direction changes.

## Experienced Patterns

- **Insight suppression**: a consequential finding or opportunity supported by available evidence is not surfaced.
- **User-dependency drift**: shallow delivery repeatedly relies on the user to discover and direct the missing design depth.
- **Recommendation avoidance**: options are listed without an independent recommendation, reasons, benefit, or cost.
- **Question dumping**: ordinary local design and implementation decisions are pushed back to the user under the guise of alignment.
- **Approved insight loss**: an accepted proposal never enters the governing target, plan, implementation, or acceptance basis.
- **Silent expansion**: a useful idea is implemented before approval even though it materially changes promise, architecture direction, data ownership, cost, schedule, or acceptance.

Confirm collaboration findings through messages, decisions, artifacts, or repeated outcomes. Do not infer what an earlier agent must have known.

When raising a consequential issue or opportunity, provide the evidence, the agent's recommended direction, the expected benefit, the material cost or downside, and what needs user confirmation. Do not replace judgment with an unranked option list.

If the evidence reveals a recurring collaboration pattern not covered here, describe it provisionally and explain how retaining it would improve future responsibility or decisions.
