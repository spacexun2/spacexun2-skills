# Target Lineage

Load this reference only when the governing target, approved evolution, or historical divergence is genuinely unclear.

Recover the target from the smallest sufficient set of sources:

1. original user request, attached artifact, initial objective, or `/goal` objective;
2. later user corrections and explicitly approved refinements, including agent-originated proposals;
3. pending or rejected proposals that clarify what is not part of the target;
4. canonical product, prompt, prototype, schema, or contract;
5. current plan, task package, automation, and agent-created control documents;
6. territory evidence showing what was actually built or run.

Do not use "newest wins." Current plans and implementation describe the route and result; they do not silently replace original intent or approved evolution.

If the original source is unavailable, label the target unverified. Do not infer a convenient target from the current implementation. Ask for the source or a user restatement only when the uncertainty changes the correction.

Locate a first divergence only when the sequence supports one. Name the earliest evidenced decision or artifact that changed the approved direction, the unsupported assumption, and its effect. An approved pivot is target evolution, not drift.
