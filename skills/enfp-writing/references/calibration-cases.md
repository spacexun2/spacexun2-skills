# 写作偏移历史档案

本文件保存 `enfp-writing` 历史迭代中出现过的偏移、用户纠正与抽象来源，供维护 Skill、复盘设计依据或审计规则来处时查阅。它不是运行时写作 reference：新写、改稿、用户指出 AI 味或候选被否决时均不加载，也不逐项扫描正文。已经稳定成立的结论应写入主 Skill 或对应 canonical reference；本表只保留其经验来处，不能与当前指令竞争。

后续纠偏确认：下表中的二元翻转句式只是一组高风险指纹，不构成禁词表。真正需要避免的是无来处的纠正读者与完成论证姿态；由真实经历、人物认识或作者此前理解推动的分析与辩证可以充分保留。

| 当前信号 | 偏移怎样发生 | 更合适的修复方向 |
| --- | --- | --- |
| 成稿用“不是 X，而是 Y”“不是 X，是 Y”或“不是 X，只是 Y”制造转折 | 句子先排除或贬低一个选项，再把另一个选项宣布为真正答案；叙述者突然像在纠正读者或完成论证 | 先辨认它承担的排误、对比、情感辨认或收束功能，再用具体行动、细节变化、真实误解、时间差或直接肯定保留这些信息 |
| 成稿避开“不是”字面，却写成“并非 X，而在于 Y”“与其说 X，不如说 Y”“不只是 X，更是 Y”“问题不在 X，在 Y”“重要的不是 X，是 Y”“没有 X，只有 Y”“看似 X，实则 Y”或“X 算不上什么，真正……的是 Y” | 表面措辞变化了，认知结构仍是先设立 X、再宣布 Y 才是真相 | 按同一种二元翻转处理；不要用另一个成对连接词替换，直接重写信息展开的顺序 |
| 材料说“直到后来才发现”，前文却已用近义判断预告答案 | 事件顺序保留了，认识的时间却被提前 | 让前文只拥有当时的行动与感受，在指定节点再命名后来理解 |
| 非虚构材料未给人物性别，成稿按名字印象使用“他/她” | 语法选择悄悄补成了人物事实 | 重复姓名、省略主语或改用中性句式，让未知保持未知 |
| 材料只有人物动作，成稿补出“我更愿意怎样记住/书写这一天” | 为了篇幅和意义增加了作者动机与回忆判断 | 用顺序、并置和动作结果组织纪事；材料承载不足时缩小范围或请求补充 |
| 材料没有说明先后、补救或持续状态，成稿用“后来”“没有再做”“一直到”补齐过程 | 连接词与否定句生成了新的可核事实 | 只用显式时间锚点；未知顺序保持并列，材料缺省保持未知 |
| 非虚构反复说明某个细节“也是经历的一部分”，并在结尾逐项重述证据 | 写作脚手架进入正文，中心被解释而非由场景生成 | 让一个关键现场与一句认识完成转变；后续只增加新层，结尾保留最强的一次回望 |
| 虚构关系用搬家次数、钥匙、点赞频率和见面记录集中证明深厚 | 人物履历替代了当前场景中的互动与选择 | 选少量会改变眼前对话的旧事，让默契、旧怨和舍不得在现场继续发生 |
| 前一句用“还没有难过”“尚未意识到”提前点名后文认识 | 否定语法仍让迟到的感受提前进入读者视野 | 用当时原话、动作或未被命名的停留搭桥，把情感命名留在它真正出现的位置 |
| 作者给出准确心理、社会或专业概念，候选将它换成柔软比喻 | 概念承担辨认功能，却被当作普通修辞润色 | 保留准确概念，只修它与前后经历的连接 |
| 一份正面情谊被连续写成“不求、不等、不是” | 编辑为了说明边界，反而把美好关系改成预先辩护 | 先写现实称呼、共同经历与作者实际感到的温暖、喜欢或珍贵；只在读者确实会误解处说明一次位置 |
| 两个并列情感词被压缩成一个更安全的近义词 | 句子更简洁，感情强度与作者确认却发生变化 | 把逐字确认的并列词视为意义，不以同义压缩替代 |
| 相邻几句或几段都提到同一个人或感觉，节奏反馈被直接翻译成缩短 | 其中可能分别承担在场、共振、原因、现实关系与后来理解；篇幅被误当成节奏 | 先辨认每处增加的时间、角度、强度和功能，再按当前原因选择换序、拆合、连接、展开或压缩；保留功能不同的层次 |
| 私密背景被直接展开成公开说明 | 背景原本只用于校正一个称呼、暗指或段落顺序 | 恢复公开正文的原有分寸，让私密信息继续留在理解层 |
| 歌词、外部引用、过去想说的话与当前感受混成作者独白 | 来源、说话者和时间层被抹平 | 逐项恢复出处与时间，再写它们如何进入当前经验 |
| “少了一些恐惧”被整理成已经坦然或治愈 | 新理解增加了一层，却被写成旧感觉消失 | 让新旧感觉并存，保留变化的真实尺度 |
| 愿望、担心或设想被改成已经发生的动作 | 候选为衔接顺畅补全了事实 | 恢复原时态，让愿望以愿望、可能以可能出现 |
| 玩笑、括号、犹疑或轻飘飘的词被统一删去 | 编辑把公开分寸与自然声音误当成不够成熟 | 判断它承担的是节拍、关系姿态还是语病；保留有功能的轻与不规整 |
| 局部认识被整理成一段完整的人生哲理 | 模型替作者补齐了论证和成长结论 | 恢复认识在经历中逐步发生的顺序，只修真正妨碍理解的连接 |

## 完整成稿的模型化迹象

交付前扫描二元翻转句及其变体。找到以后，先问 X 是否来自真实误解、人物当场排查或必须保留的对比：若没有，直接写 Y 或让具体场景承担判断；若有，让误解从人物和情境中实际发生，再由后续事实改变认识。替换时保留原句的有效信息，不把所有句子统一改成另一种固定模板。引用内容或作者明确要求逐字保留的原句不擅自改写，另行提示冲突。

如果文章每段长度相近、总用相似短句收尾、反复把局部感觉提升为标题或结论，先恢复材料本来的密度差异：群体片段可以热闹并容纳名字，个人认识可以放慢，关系表达可以直接解释，一段小事也可以没有意义总结。

如果文字依靠通用天气、光线、风景、对白和身体感制造真实，回到当前材料真正提供的触发物。若语体靠均匀添加括号、网络语、专业词或意象制造“ENFP”，让每种语言只在当前人物、场景和注意力确实需要时出现。

校准完成后，重新比较 current body 与候选：事实、时态、人物姿态、感情强度和句子节拍是否仍属于同一个作者。只修当前出现的偏移，不逐项套用整个案例库。
